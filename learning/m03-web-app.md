# Milestone 3: Web App (Next.js, Dashboard, and Step 1 Script Editor)

1. Next.js App Router with static export (`output: 'export'`) enables instant global hosting while communicating securely with Axum via HttpOnly session cookies and CSRF headers.
2. Section boundary splitting on blank lines (`\n\n`) naturally decomposes continuous text into scene blocks while preserving exact concatenated script integrity.
3. Decoupling editor state history through Zustand and Zundo guarantees fast local undo/redo (50+ steps) and seamless debounced autosaving to the server.
